# 変更メモ: FE-0 フロント足場（M0）

**日付**: 2026-04-11

## 内容

[段階実装（frontend）.md §FE-0](../段階実装（frontend）.md) に沿い、`frontend/` に Next.js 16（App Router）・TypeScript・ESLint・Tailwind v4 の足場を追加。

## 新規・主なファイル

| パス | 説明 |
|------|------|
| `frontend/` | `create-next-app` 生成一式（ネスト `.git` は削除しモノレポに統合） |
| `frontend/app/globals.css` | スペーシング・Primary/Neutral/Semantic の CSS Variables、`@theme` 連携、`prefers-reduced-motion` |
| `frontend/app/page.tsx` | プレースホルダトップ |
| `frontend/.env.example` | `NEXT_PUBLIC_API_BASE_URL` とサーバ専用キーのコメント |
| `frontend/README.md` | 起動手順・環境変数・レイヤリング方針 |
| `.gitignore`（ルート） | `.env` / `.env.*.local` / `.DS_Store` |

## 設定変更

| 項目 | 内容 |
|------|------|
| `frontend/eslint.config.mjs` | `@typescript-eslint/no-explicit-any`: error |
| `frontend/.gitignore` | `.env.example` をコミット可能に（`.env` / `*.local` のみ除外）、`next-env.d.ts` を追跡対象に |
| `frontend/app/layout.tsx` | メタデータ・`lang="ja"` |

```bash
cd frontend && npm run lint && npm run build
```
