## 検証コマンド（開発者が手元で実行）

プランにより **エージェントは実行していない**。

```bash
cd backend
python3.13 -m venv .venv
source .venv/bin/activate
pip install -r requirements-dev.txt
pyright
pytest
uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```
